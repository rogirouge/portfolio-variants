Ce site

Un tirage passe par trois bains : révélateur, arrêt, fixateur. Ce site aussi : build, test, publication.

Une page écrite à la main, sans framework. À chaque git push, GitHub Actions construit une image Docker (nginx, sans les droits root, conteneur en lecture seule), vérifie que les pages, les en-têtes et la page 404 répondent, publie l'image sur ghcr.io, puis met cette page en ligne sur GitHub Pages.

Chaque image porte le hash de son commit : on peut revenir à n'importe quelle version.
