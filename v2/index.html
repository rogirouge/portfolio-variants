Projet

Ce site

Une page écrite à la main, sans framework, servie par nginx dans un conteneur Docker. À chaque git push, GitHub Actions construit l'image pour amd64 et arm64, la démarre, vérifie que les pages, les en-têtes et la page 404 répondent correctement, puis la publie sur ghcr.io.

nginx tourne sans les droits root, dans un conteneur en lecture seule. Chaque image porte le hash de son commit, ce qui permet de revenir à n'importe quelle version.

Prochaine étape : le déploiement automatique sur un serveur Oracle Cloud, puis un nom de domaine et HTTPS.
