Projet

Ce site

push → build → test → publish → deploy

Une page écrite à la main, sans framework, servie par nginx dans un conteneur Docker. À chaque git push, GitHub Actions construit l'image pour amd64 et arm64, la démarre, vérifie que les pages, les en-têtes et la page 404 répondent, puis la publie sur ghcr.io.

nginx tourne sans les droits root, dans un conteneur en lecture seule, et chaque image porte le hash de son commit. Prochaine étape : le déploiement automatique sur un serveur Oracle Cloud.
