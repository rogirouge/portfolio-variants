Ce site

PushBuildTestPublish

À chaque git push, ce site se reconstruit, se teste et se publie tout seul.

Une page écrite à la main, sans framework. GitHub Actions construit une image Docker (nginx sans les droits root, conteneur en lecture seule), vérifie que les pages, les en-têtes et la page 404 répondent, publie l'image sur ghcr.io, puis met cette page en ligne sur GitHub Pages.

Chaque image porte le hash de son commit : on peut revenir à n'importe quelle version.
